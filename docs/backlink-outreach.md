## ⚠️ 数値の読み方（重要）

- **`blog.jp` / `livedoor.blog` の DR 80〜86 は鵜呑み厳禁** — livedoorブログ全体のDRを継承しているだけで、個別ブログの「リンク資産としての強さ」を反映していない。**実態は `refdomains`（その個別ブログに直接リンクしている独自ドメイン数）で評価する**
- **`org_traffic`（月間オーガニック検索流入）がゼロのサイトは、検索エンジンからほぼ無視されている** — 相互リンクを設置してもらってもクローラの導線として機能しない
- 自動相互リンク集（A-1/エロリスト/ヒーハー）は refdomains 200〜300あるが、相互登録サイト同士の相互リンクで膨らんでいるだけで質は低い

## 優先度サマリ（実数値ベース）

### ★★★ 最優先（流入＆refdomainsが実在する4サイト）
**#1 imageika / #2 llive / #3 antenna.ai-gazoukan / #4 erogazoudesuwa**

この4つは月間オーガニック流入が実数値（500〜5,000）あり、独自被リンクも積み上がっている。**av-hakase.com の被リンク獲得という観点で実効性が最も高い**。連絡文を丁寧に作って個別対応する。

### ★★ 中優先（権威 or 親和性で意義あり）
**#5 dennou2.x.2nt（老舗） / #6 irusunatchi / #7 deon3 / #8 db.ivnikki / #9 imacap**

流入は薄いが、refdomains が一定数あり、ジャンル親和性も高い。テンプレート流用で連絡。

### ★ 補欠（数稼ぎ・自動登録）
**#10〜#13: chaptercapture2 + 自動相互リンク集3兄弟（A-1/エロリスト/ヒーハー）**

自動登録系は **「設置すれば被リンクが付く」反面、相互リンクスパム判定リスクあり**。自社からのリンク設置量を制限する形での運用推奨。chaptercapture2は規模はあるがrefdomains 13と個別評価は低め。

### ☆ ついで枠（連絡コストが小さければ申請可、効果は期待しない）
**#14〜#20**

refdomains が一桁台の個人ブログ群。検索流入ゼロ。連絡しても被リンクSEO効果はほぼゼロだが、コメント申請型でコスト小さいなら数稼ぎとして。

## 重要な戦略示唆

1. **「DR 86だから強い」は嘘** — blog.jp 系5サイトのうち、実質パワーが多少でもあるのは imacap (refdomains 27) と chaptercapture2 (13) のみ。残り3つ (shu7harem, avgazo, gravian-av) は申請しても被リンク評価ほぼ得られない
2. **本命★★★4サイトに集中投資すべき** — 4社全部で交渉成立すれば、合計 refdomains 1,990 のサイトから被リンク獲得。これだけで初期被リンク基盤として十分
3. **自動相互リンク集（A-1系）は最後に判断** — Googleの低品質相互リンク判定リスクと、refdomains数の確実獲得のトレードオフ。本命★★★が成立した後に検討する順番でよい
4. **erogazoudesuwa.com の DR9 / refdomains 761 という乖離が示すこと** — 大量の弱い被リンクで refdomains 数だけ膨らんでいる可能性。アクセス内訳を見て、実流入が571あるなら獲得価値あり

## 運用ルール

1. **連絡前に必ず先方サイトへのリンクを当方サイト（リンク集ページ）に設置する** — 後出しよりも先出しのほうが承諾率が高い
2. **1日に送る件数は5件以内** — スパム的に見えないよう小ロットで
3. **連絡から1週間返信なし → 「保留」に変更**、2週間で「要再確認」
4. **獲得済になったらリンクが本当に設置されているか月1で確認** — 外されていた場合「要再確認」に戻す
5. **自動登録系（#11〜#13）はリンク先が低品質と判断されたら自サイト側のリンクごと削除する判断もあり**
6. **★★★4サイトが承諾されたら、3ヶ月後にav-hakase.comの被リンク状況をAhrefsで再計測** — 効果が確認できたら次のロットへ

## 数値ソース

- Ahrefs API v3 `batch-analysis`（country=jp, mode=subdomains, protocol=both）
- 取得日: 2026-04-25
- 数値の意味
  - **DR (Domain Rating)**: 被リンクプロファイルの強さ（0〜100の対数スケール）
  - **org_traffic**: 月間オーガニック検索からの推定流入数
  - **refdomains**: そのサイトに被リンクを送っているユニークドメイン数（質の指標）
  - **backlinks_dofollow**: dofollow扱いの被リンク総数（数だけ多くても refdomains が少なければ価値低）
