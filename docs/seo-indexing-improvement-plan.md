## 結論（3行）

1. **クロールバジェット問題でGoogleにほぼ発見されていない**（22,396 URLに対しindexed=0）
2. **日本ユーザーの主戦場は女優×ジャンルページ（fanza_click 86%）** のため、削減しすぎるとCVを大きく失うリスクあり
3. **「Phase A: サイトマップ除外のみ」から段階運用** が低リスク高効果

## 3. アクションプラン

> **方針**: 日本ユーザーfanza_clickへの影響を最小化しつつ、クロールバジェット問題を解消する。
> **当初の「10本未満noindex」は日本CVを48%失うリスクがあったため、閾値を厳しくしすぎず段階運用に変更**。

### 🔥 P0: 構造修正（今週・低リスク高効果）

#### ① 女優×ジャンルページの段階的整理

**Phase A: サイトマップ除外のみ（noindex なし）** ← 最初に実施・低リスク

- **対象**: 親女優の作品数 < 30本 のジャンルページ全て、および該当作品数 < 3本 のジャンルページ
- **効果**: サイトマップから 21,361 → 約5,000-7,000 に削減（クロール優先度を主要ページに集約）
- **リスク**: 既存インデックスは残るので **検索面の喪失はゼロ**
- **失う日本fanza_click 推定**: ほぼゼロ（既存indexから流入は維持）

**Phase B: noindex 化（Phase A から1〜2ヶ月後に判断）**

- **対象判断基準**:
  - 該当作品数 < 3本 → noindex（日本fanza_click影響: -9.6%、許容範囲）
  - 該当作品数 3-5本 で滞在8秒のページ → 個別判断
- **6-10本以上は noindex しない**（日本のCV源として実績あり: 105 click / 14日）

**実装箇所**:
- `meikan/src/controllers/SitemapController.php` で出力時にフィルタ強化（Phase A）
- `meikan/templates/genre.php` に `<meta name="robots" content="noindex">` 出力（Phase B）
- `meikan/src/controllers/GenreController.php` で判定ロジック追加（Phase B）

**期待効果**: Phase A だけでクロールバジェット問題はほぼ解消。Phase B は効果見極めて段階適用。

#### ② 作品数1-2本の女優ページを noindex 化

**根拠**:
- 1-2本: 46ページ存在、日本fanza_click はわずか2件（影響軽微）
- 滞在時間 20秒（サイト平均 54秒の37%）
- thin content扱いされやすい

**当初提案の修正**: 当初「1-5本noindex」としていたが、3-5本は日本fanza_click 7件あるため**1-2本のみに絞る**。

**実装箇所**:
- `meikan/templates/actress.php` に noindex 条件出力
- `meikan/src/controllers/ActressController.php` で判定

#### ③ サイトマップ分割

**現状**: 22,396 URLをひとつのファイルに優先度ほぼ平坦で出力 → Google が indexed=0 と無視

**改善後**:
```
sitemap.xml  ← index sitemap（下記4つを束ねる）
├── sitemap-core.xml      （TOP/名鑑/記事一覧 ~30 URL, priority 1.0）
├── sitemap-articles.xml  （個別記事 ~80 URL, priority 0.8）
├── sitemap-actresses.xml （作品数3本以上の女優 ~1,000 URL, priority 0.7）
└── sitemap-genres.xml    （①Phase Aで絞った ~5,000-7,000 URL, priority 0.5）
```

**実装箇所**:
- `meikan/index.php` にルート追加（`sitemap-core.xml` 等）
- `meikan/src/controllers/SitemapController.php` を分割対応に改修

#### ④ GSC で fanza_click TOP10 の未インデックスページに「インデックス登録リクエスト」

手動で30件/日まで可能。即時クロール対象に格上げされる。

**対象例**:
- /kiyono-saki/
- /shinoda-yuu/
- /hatano-yui/
- /hasumi-kurea/
- /mikami-yua/
- /hashimoto-arina/
- /kaori/
- /rui-2/
- /anzai-rara/
- /horikita-moea/

P0-①〜③のコード反映後、本番デプロイ → GSCで再submit → 最後に④。
